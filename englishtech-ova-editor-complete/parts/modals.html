Integración en EnglishTech

Cómo implantar este editor o visualizador en englishtech.vercel.app

Puedes implantar los Objetos Virtuales de Aprendizaje en tu plataforma EnglishTech de dos formas muy sencillas:

Opción 1: Como Componente React Nativo (Recomendado) Vite / Next.js / React

Copia los archivos OvaViewer.tsx y types.ts generados en la carpeta src/components/ a tu proyecto de EnglishTech, y utilízalos así: 

import { OvaViewer } from '@/components/OvaViewer';
import goldenRatioData from '@/templates/goldenRatioOva.json';

export default function ModuloOva() {
  return (
    <div className="min-h-screen bg-slate-950">
      <OvaViewer data={goldenRatioData} />
    </div>
  );
}
Opción 2: Como Módulo HTML Autónomo Cero dependencias

Descarga el archivo con el botón «Descargar OVA» y colócalo en tu carpeta public/ova/index.html de EnglishTech. Puedes acceder directamente en https://englishtech.vercel.app/ova/ o mostrarlo dentro de un <iframe src="/ova/index.html" />.
